# Create Weekly Status Report

Generate a weekly status report from the work provided. Write the report only. Do not add commentary, a preamble, or a closing note.

## Output

- Format: Markdown.
- Sections, in this order, each as a level-2 heading:
  - Accomplishments
  - Blockers
  - Next week
- Bullet points only. No paragraphs, tables, or numbered lists.
- Maximum 20 lines, including headings and blank lines.
- Professional tone.
- No fluff words. State the fact, the owner, and the date or impact when known. Omit praise, hedging, and filler.

## Section rules

- **Accomplishments.** Work finished this week. Past tense. One outcome per bullet.
- **Blockers.** What is stopped, why, and who must act. If nothing is blocked, one bullet: `None.`
- **Next week.** Outcomes planned for the coming week. One outcome per bullet. Do not restate the backlog.

## Style

- Use concrete nouns and verbs.
- Drop words that add no fact: very, really, just, basically, hopefully, exciting, great, significant, leverage, robust, seamless.
- Keep each bullet to one sentence.
- Do not invent work, dates, owners, or blockers that were not supplied.
